# BottlePOS

BottlePOS — Intelligent Liquor Store POS & Loss Prevention Platform

## Overview
BottlePOS is a modern backend foundation designed specifically for liquor and bottle stores. It supports operational workflows required by modern liquor retailers, including POS transactions, liquor-specific inventory management, and an advanced AI-assisted loss prevention engine called **BottlePOS Shield**.

## Architecture
The system is built on Python 3.12+ using **FastAPI** and **Pydantic**, adhering to Clean Architecture principles.
Currently, it uses an **in-memory repository pattern** ensuring NO database dependency for this phase, but is fully ready to be swapped out for a PostgreSQL implementation in the future.

### Key Components
- **Domain Models (`app/domain`)**: Core business entities representing POS state (Products, Inventory, Transactions, etc.).
- **Schemas (`app/schemas`)**: Pydantic models for API request/response validation.
- **Services (`app/services`)**: Core business logic and transaction boundaries.
- **Repositories (`app/repositories`)**: Interfaces and thread-safe in-memory implementations for data persistence.
- **Event Bus (`app/events`)**: In-process event architecture for decoupling business actions from loss prevention analysis.
- **BottlePOS Shield (`app/services/shield`)**: The flagship feature that uses rule-based, statistical, and correlation engines to detect anomalies, calculate financial exposure, and generate risk alerts.

## Setup & Installation

### Prerequisites
- Python 3.12+
- `pip` or `uv`

### Installation
1. Clone the repository.
2. Navigate to the backend directory:
   ```bash
   cd backend
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Copy the environment configuration:
   ```bash
   cp .env.example .env
   ```

### Running the Backend Server
Start the FastAPI server from the `backend` directory using Uvicorn:
```bash
uvicorn app.main:app --reload
```

### Docker Deployment
Build and run the production backend container from the `backend` directory:
```bash
cd backend
docker build -t bottlepos-backend .
docker run -p 8000:8000 bottlepos-backend
```

## API Documentation
Once the server is running, you can access the interactive API documentation at:
- Swagger UI: `http://localhost:8000/docs`
- ReDoc: `http://localhost:8000/redoc`

## Demo
A deterministic demo script is included to populate the system with mock data and trigger specific BottlePOS Shield fraud detection scenarios (Rule-based anomaly and Correlated event anomaly).

Run the demo from the `backend` directory:
```bash
python -m app.scripts.demo
```

## Testing
Run the automated test suite from the `backend` directory using pytest:
```bash
pytest
```
